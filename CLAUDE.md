# Code Quality & Simplicity

- Always prioritize clean code and simple solutions. The resulting code must be highly readable and maintainable, avoiding unnecessary complexity or over-engineering.

# Project Context & Reusability

- Always prefer using existing project components, utility functions, and variables. Before writing new code, check for and utilize available resources to ensure consistency and minimize duplication.

# Risk Management & Confirmation

- Always ask for confirmation before generating or implementing high-risk code segments. High-risk code includes actions that might:
  - Modify core logic (e.g., authentication, payment).
  - Perform destructive database operations (e.g., DELETE, DROP).
  - Introduce significant performance bottlenecks.
